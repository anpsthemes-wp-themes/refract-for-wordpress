# Security policy

## Supported versions

We fix security issues in the latest version of Refract for WordPress. Update to it before you report an issue, and
check that the issue is still there.

## Reporting a vulnerability

Email support@anpsthemes.com. Don't open a public issue, and don't post the details anywhere else until we have
released a fix.

Please include:

- The plugin version, and the versions of WordPress and PHP.
- What an attacker can do, and what they need first (for example, a logged-in Author account).
- The steps to reproduce it, with any requests or code you used.
- Whether the issue is already public or known to others.

## What happens next

We reply to tell you we have your report. We check the issue, and if it's real, we fix it and release a new version.
We tell you when the fix is out, and we credit you in the changelog if you want us to. We don't run a bug bounty.

Issues with Refract itself (https://refract.social) go to the same address.
